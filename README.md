GuaguaTime RD es un simulador sencillo de rutas y costos del transporte público en República Dominicana. Permite seleccionar el origen, destino y condiciones como lluvia u hora pico para calcular el costo y el tiempo estimado del viaje.

Características:

-Selección de origen y destino. -Opción de ordenar por tiempo o costo. -Condiciones adicionales como lluvia y hora pico. -Modo ahorro y cambio de idioma (ES/EN). -Resultados mostrados de forma simple sin necesidad de base de datos.

Tecnologías utilizadas:

-HTML5-JavaScript (ES6)-CSS
